# KakaoMap SDK 사용 가이드

## 기본 규칙

KakaoMap SDK는 브라우저 전용 라이브러리입니다. **반드시 `dynamic()` import로 SSR을 비활성화해야 합니다.**

```tsx
import dynamic from 'next/dynamic'

const KakaoMap = dynamic(() => import('@/components/KakaoMap'), {
  ssr: false,
  loading: () => <div className="w-full h-full bg-gray-100 animate-pulse" />,
})
```

일반 import로 불러오면 서버 렌더링 시 `window is not defined` 에러가 발생합니다.

---

## 카카오맵 키 접근

`config.kakaoMapKey`는 lazy getter입니다. 실제 SDK를 초기화하는 시점에만 접근하세요.

```ts
import { config } from '@/lib/config'

// KakaoMap 컴포넌트 내부 (클라이언트 사이드)
const key = config.kakaoMapKey
```

컴포넌트 외부(모듈 최상단)에서 접근하면 SSR 시 에러가 날 수 있습니다.

---

## 카카오 콘솔 설정

카카오맵 키는 카카오 개발자 콘솔에서 **도메인 화이트리스트 등록이 필수**입니다.

- 개발: `http://localhost:3000`
- 운영: 실제 서비스 도메인

도메인 미등록 시 지도가 렌더링되지 않습니다.

---

## window.kakao 타입

`src/types/kakao.d.ts`에 SDK 타입이 선언되어 있습니다. 별도 import 없이 `kakao.maps.*` 형태로 사용합니다.

```ts
// 타입 선언이 전역으로 등록되어 있어 import 불필요
const map = new kakao.maps.Map(container, options)
const marker = new kakao.maps.Marker({ position })
```
